TROUBLESHOOTING QUICK FIXES
─────────────────────────────────────────────────────────────────────────────────

PROBLEM: "Syntax error"
→ Check for quotes, commas, and parentheses in data
→ Look at the exact SQL error message
→ Copy just one row to test format

PROBLEM: "Foreign key violation"
→ Make sure USERS imported before VENDORS/DRIVERS
→ Check that user_id values exist in users table

PROBLEM: "Counts don't match"
→ One table didn't import completely
→ Check for SQL error messages
→ Count individual tables to find which one failed
→ Re-run just that table's import

PROBLEM: "App says 'Connection failed'"
→ Restart app completely
→ Check .env file has NEW account URL
→ Try a different network (WiFi vs cellular)

PROBLEM: "App crashes on login"
→ Check that user_id from migrated data is valid
→ Try with a different user
→ Check app logs for error message
