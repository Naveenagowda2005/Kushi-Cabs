   Settings → Developer Options → Wireless Debugging → Enable
   Note the IP address shown (e.g., 192.168.1.100)

2. On Computer:
   adb connect 192.168.1.100:5555
   adb devices  (verify connection)
   adb install "C:\Path\To\app-release.apk"

3. On Phone:
   Tap "Kushi Cabs" icon to launch

🆘 COMMON ISSUES
───────────────────────────────────────────────────────────────────────────────

Issue: "eas command not found"
Fix:   npm install -g eas-cli

Issue: "expo command not found"
Fix:   npm install -g expo-cli

Issue: "Build failed"
Fix:   eas build --status (check error)
       npm cache clean --force
       npm install --legacy-peer-deps
       eas build --platform android --profile production

Issue: "App won't install"
Fix:   adb uninstall com.Kushi_Cabs
       adb install app-release.apk

Issue: "App crashes immediately"
Fix:   adb logcat | findstr "Kushi" (check logs)
       Verify .env has all required variables

Issue: "Phone not detected by ADB"
Fix:   adb kill-server
       adb start-server
       adb connect 192.168.x.x:5555

5. Keep dependencies updated: npm install
6. Use development profile for rapid testing
