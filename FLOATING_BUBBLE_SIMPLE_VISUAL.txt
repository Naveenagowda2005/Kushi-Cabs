INTERACTION GUIDE
═════════════════════════════════════════════════════════════════════════════════

    USER ACTION                          WHAT HAPPENS
    ─────────────────────────────────────────────────────────────────────────

    1. App goes to background            → Floating bubble appears
       (Press Home button)               → Animation: scales in

    2. Tap on bubble circle              → App opens
                                         → Shows Active Trip screen
                                         → Bubble disappears

    3. Tap on dropdown arrow (▼)         → Dropdown menu opens
                                         → Arrow rotates to (▲)
                                         → Shows trip details

    4. Tap on trip card (in dropdown)    → App opens
                                         → Shows Active Trip screen

    5. Tap dropdown arrow again (▲)      → Dropdown menu closes
                                         → Arrow rotates back to (▼)

    6. App comes to foreground           → Bubble disappears
       (Tap Home or open app)            → Animation: scales out

What does this mean?

✅ WORKS EVEN WHEN:
   • App is in background (minimized)
   • Different app is in foreground
   • Screen is locked (may need special handling)
   • User is using any other app

✅ APPEARS OVER:
   • Messages, Maps, Camera
   • Settings, Dialer, Browser
   • Games, Videos, Social Media
   • ANY app on the phone!

✅ ALWAYS VISIBLE:
   • As long as trip is active (in_progress)
   • Stays on top of everything
   • User can interact with it from anywhere

✅ DISAPPEARS WHEN:
   • App comes to foreground
   • Trip status changes from in_progress
   • User closes the app

READY TO SEE IT IN ACTION?

Build the APK and test:
  1. expo prebuild --clean
  2. cd android && ./gradlew assembleRelease
  3. Install APK on your phone
  4. Create an active trip
  5. Press HOME button
  6. See the floating bubble appear! 🎉
