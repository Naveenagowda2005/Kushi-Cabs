🚀 QUICK START: 3 SIMPLE STEPS
================================================================================

Step 1: Setup System (First Time - 1-2 hours)
  $ Follow: SYSTEM_SETUP_REQUIREMENTS.md
  ✓ Install Java JDK 21
  ✓ Install Android SDK (8-10 GB)
  ✓ Setup environment variables
  ✓ Enable phone developer mode
  ✓ Install npm dependencies

Step 2: Build APK (15-30 minutes)
  $ cd "c:\New folder\Kushi-Cabs-master (1)\Kushi-Cabs-master\newtaxi\apps\unified"
  $ eas login
  $ eas build --platform android --profile production
  ✓ Download APK when build completes

Step 3: Install on Phone (5 minutes)
  $ adb connect 192.168.x.x:5555        # Phone IP from Developer Options
  $ adb install app-release.apk
  ✓ App appears on phone - Done!

Total Time: 2-3 hours first time, 30-45 minutes for subsequent builds
