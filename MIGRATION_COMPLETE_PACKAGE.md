## 📞 Getting Help

### If Something Goes Wrong

1. **Check the issue** in the file that applies:
   - COUNT MISMATCH → See "Data Migration Guide - Troubleshooting"
   - SQL ERROR → Look at the exact error message
   - APP WON'T CONNECT → Check `.env` file
   - DATA LOOKS WRONG → Verify export format

2. **Common fixes:**
   - Import tables in correct order
   - Make sure all data is properly formatted
   - Verify NULL values are handled
   - Check for special characters

3. **Still stuck?**
   - Re-read the relevant section
   - Check SQL error messages closely
   - Try one table at a time
   - Review the verification checklist
