ANIMATION TIMING
═══════════════════════════════════════════════════════════════════════════════════

Bubble Appear:
  Duration:   300-400ms
  Type:       Spring animation
  Effect:     Scale 0 → 1, Opacity 0 → 1

Bubble Disappear:
  Duration:   200-300ms
  Type:       Spring animation
  Effect:     Scale 1 → 0, Opacity 1 → 0

Dropdown Open:
  Duration:   100-150ms
  Arrow Rotation: 0° → 180°
  Menu Opacity:   0 → 1

Dropdown Close:
  Duration:   100ms
  Arrow Rotation: 180° → 0°
  Menu Opacity:   1 → 0

Tap Feedback:
  Duration:   100-150ms
  Effect:     Scale 1 → 0.95 → 1
