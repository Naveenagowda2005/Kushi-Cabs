private void playNotificationSound() {
    try {
        if (audioManager != null) {
            Uri soundUri = RingtoneManager.getDefaultUri(
                RingtoneManager.TYPE_NOTIFICATION
            );
            
            android.media.Ringtone ringtone = 
                RingtoneManager.getRingtone(this, soundUri);
            ringtone.play();
            
            Log.d(TAG, "Notification sound played");
        }
    } catch (Exception e) {
        Log.e(TAG, "Error playing sound: " + e.getMessage());
    }
}

================================================================================
SOUND + VIBRATION COMBINATION
================================================================================

When Trip Count Changes:

1. SOUND               🔊 Android notification tone plays
   - Default system sound
   - ~1 second duration
   - Respects device volume settings

2. VIBRATION          📳 Phone vibrates with pattern:
   - Vibrate 50ms
   - Wait 100ms
   - Vibrate 50ms
   - Total: ~200ms

3. VISUAL             🫧 Badge animates:
   - Scale up (1.0 → 1.3)
   - Scale down (1.3 → 1.0)
   - Updates with new count

4. ANIMATION          🌀 GPS radar continues pulsing

Result: MULTI-SENSORY ALERT for driver!

================================================================================
SOUND RESPECTS DEVICE SETTINGS
================================================================================

Silent Mode:
  ON  → Sound muted, vibration triggers
  OFF → Sound plays at notification volume

Do Not Disturb (DND):
  ON  → Sound muted (priority notification may still vibrate)
  OFF → Sound plays normally

Notification Volume:
  0%  → Silent (but vibration works)
  50% → Medium volume
  100% → Full volume

================================================================================
FUTURE CUSTOMIZATION OPTIONS
================================================================================

If want custom sound, can:

Option 1: Use a different system sound type
  RingtoneManager.TYPE_ALARM (louder)
  RingtoneManager.TYPE_RINGTONE (even louder)
  RingtoneManager.TYPE_NOTIFICATION (current)

Option 2: Add custom sound file
  1. Add trip_notification.mp3 to res/raw/
  2. Update code:
     Uri soundUri = Uri.parse("android.resource://" + 
         getPackageName() + "/" + R.raw.trip_notification);
  3. Play custom sound

Option 3: Use MediaPlayer for full control
  More complex but allows:
  - Loop/repeat
  - Volume control
  - Multiple sounds
  - Stop functionality

Current implementation: ✅ OPTIMAL for production
