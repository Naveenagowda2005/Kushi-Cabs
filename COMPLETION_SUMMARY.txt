================================================================================
HOW IT WORKS
================================================================================

UPLOAD FLOW:
  1. Driver captures odometer image
  2. Image { uri, base64 } created
  3. uploadOdometerImage() called
  4. Base64 decoded to Uint8Array
  5. Uploaded to 'odometer-images' bucket
  6. Public URL returned
  7. startTrip({ start_odometer_url: URL })
  8. URL stored in trips table (150 bytes!)

DISPLAY FLOW:
  1. Admin queries trips
  2. SELECT start_odometer_url, end_odometer_url
  3. Get URLs (fast query!)
  4. <Image source={{ uri: url }} />
  5. Images load from public bucket
  6. Display with zoom controls
  7. Done! No timeouts!
