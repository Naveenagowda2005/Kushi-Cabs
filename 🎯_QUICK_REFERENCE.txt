🚀 NEXT: 4 SIMPLE STEPS (20 minutes total)

STEP 1 - Apply Migration (2 min)
─────────────────────────────────
  1. https://app.supabase.com → SQL Editor
  2. Paste: newtaxi/supabase/migrations/101_create_storage_buckets.sql
  3. Click Run
  4. ✅ Wait for green checkmark

STEP 2 - Run Migration API (5 min)
──────────────────────────────────
  Get token: Settings → API → Service Role (copy)
  
  Command 1 - Migrate Documents:
    curl -X POST https://kushi-cabs-27p8.onrender.com/api/storage-migration/migrate-documents \
      -H "Authorization: Bearer TOKEN" -H "Content-Type: application/json" -d '{}'
  
  Command 2 - Migrate Avatars:
    curl -X POST https://kushi-cabs-27p8.onrender.com/api/storage-migration/migrate-avatars \
      -H "Authorization: Bearer TOKEN" -H "Content-Type: application/json" -d '{}'
  
  Command 3 - Check Status:
    curl -X GET https://kushi-cabs-27p8.onrender.com/api/storage-migration/status \
      -H "Authorization: Bearer TOKEN"
  
  ✅ Verify: stillInBase64 = 0 for both documents and avatars

STEP 3 - Build APK (10 min)
───────────────────────────
  cd newtaxi/apps/unified
  npx eas build -p android --wait
  
  ✅ Get download URL

STEP 4 - Commit & Push (2 min)
──────────────────────────────
  git add .
  git commit -m "Storage buckets: Move images/docs to CDN for 5-10x faster loading"
  git push origin master
  
  ✅ Done!
